## Запуск

Windows x86_64: `after_silence/build/AfterSilence.exe`. Установка Godot для игры не нужна. Для разработки импортируйте `project.godot` в Godot 4.7.2.

WASD/стрелки — движение; Shift — бег; E — взаимодействие; 1–4 — переключатели; пробел — уклонение или защита; J — журнал; Esc — пауза. В архивном эпизоде доступны также Tab — отголосок и I — предметы. В диалогах есть прокрутка и клавиатурный фокус.

В архивном эпизоде город, библиотека и лес имеют две версии реальности: там есть пять NPC, головоломки, улики, преследователь, сверка свидетельств и два финала. В новой основной истории эти места и жители сохранены, а сюжет ведут игровые события и четыре новых финала.

Автосохранение работает при переходах и после сюжетных решений, ручное — через паузу.
Новый чистый профиль: `%APPDATA%/AfterSilenceDesktop`. Старые данные в
`%APPDATA%/AfterSilence` не изменяются. Новая история использует `rift_slot.json`,
архив — `episode_slot.json`; доступны три слота. Схема состояния 3 читает старые
v2-данные, SHA-256, временный файл и резервная копия. QA использует отдельные слоты.

## Проверка

`./after_silence/build_windows.ps1` выполняет импорт, GUT, сквозные прогоны обеих историй и Windows-экспорт. Движок и шаблоны по умолчанию находятся в `C:/Games/Tools/Godot`; параметр `-Godot` меняет путь к движку. Скрипт проверяет журнал, поскольку Godot может возвращать 0 при ошибках GDScript.

Для оконного сквозного прогона запустите Godot с аргументами `--path . --script after_silence/tests/run_episode.gd -- --qa`. Подробные результаты: [DEVELOPMENT_STATE.md](DEVELOPMENT_STATE.md). Маршрут со спойлерами: [WALKTHROUGH_RU.md](after_silence/WALKTHROUGH_RU.md).

Цель 20–30 минут требует независимого плейтеста; автоматический прогон не измеряет прохождение человеком. Особняк и подземелья относятся к следующему этапу.
