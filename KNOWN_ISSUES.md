# Известные ограничения 0.9.0 Pre-Release

| Область | Статус |
| --- | --- |
| Независимый плейтест | Человеческий прогон недоступен. Продолжительность и понятность без разработчика пока не измерены. |
| Чистая Windows | EXE проверен на доступной Windows с локальным OpenGL. Запуск на отдельной чистой установке требует проверки. |
| Производительность | Есть короткий замер 1080p на Intel Iris Xe. Долгие игровые сессии и другие встроенные GPU требуют проверки. |
| Сохранения | Проверены штатная загрузка, повреждение первичного файла и перезапуск с изолированным профилем. Аварийное отключение питания и одновременная игра из двух процессов не моделировались. |
| Obsidian | 1.15.1 обнаружен. Запуск отдельного профиля завершился системной ошибкой Electron `uv_os_get_passwd / ENOMEM` в текущем окружении. Граф и Bases проверены по файлам и структуре. Визуальная проверка в приложении ожидается. |

До 1.0 остаются слепой плейтест двух развязок, проверка запуска на чистой Windows, длительный прогон на слабом ноутбуке и исправления по наблюдениям тестировщиков.
