# Исследование открытых реализаций

Репозитории изучены 15.11.2026. Временные клоны — work/research-*, не входят
в выпуск или Git. Новые активности реализованы в существующей архитектуре;
чужие демо, музыку и глобальные менеджеры целиком не подключали.

Дополнительные архитектурные опоры уже изучены и частично присутствуют в проекте:

* https://github.com/derkork/godot-statecharts — явные состояния, guards,
  пауза, сериализация. Для девяти сцен используется собственный небольшой director.
* https://github.com/grgy078033/godot-simulation-plugins/tree/main/npc-routine-scheduler
  — смена ограниченного списка занятий; существующие JSON-расписания сохранены
  для архива, новая постановка использует небольшие локальные маршруты.
* https://github.com/vanquyt-games/npc-talkkit — разделение показа разговора
  и игровых последствий; существующий UI игры остаётся основным.
* https://github.com/CodingQuests/godot-dialogue-quest-system — цели по событиям,
  conditions/effects. Новая кампания хранит переходы, решения и последствия в JSON.
* https://github.com/bitbrain/beehave — уже установлен для архивных боссов;
  не дублируется вторым AI-фреймворком.

Проверка совместимости: новый код запускается на локальном Godot 4.7.2,
проходит headless и OpenGL-тесты. Исходные 4.0-проекты не объявляются
совместимыми с 4.7.2 без портирования: их сценовые графы и ассеты не импортированы.
Новых runtime-зависимостей нет. Из внешнего исходного кода заимствованы
архитектурные приёмы; дословные фрагменты этих трёх репозиториев не копировались.
