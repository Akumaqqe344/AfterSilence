# After Silence 0.30.0 · Графика на базе PPAE

Обновление построено поверх рабочей версии 0.29.1. Карты, заключённые в них события, управление, маршруты, сюжет и формат сохранений принадлежат игре. PPAE участвует в сборке графики. Windows-игра читает запечённые PNG и метаданные и запускается без Node.js.

## Повторная сборка

Из корня AfterSilence-Source, в PowerShell с Node.js 26:

~~~powershell
git clone --branch master https://github.com/Mairon31/ppae-engine.git work/ppae-engine
git -C work/ppae-engine checkout ed98da220d9ac30e35b23da555d60f5a0ec84a51
npm.cmd --prefix work/ppae-engine ci
npm.cmd --prefix work/ppae-engine run build
npm.cmd --prefix after_silence/tools/ppae ci
node after_silence/tools/ppae/generate.mts
~~~

Рабочий checkout PPAE и каталог вывода можно передать первым и вторым параметром генератора. Без параметров результаты сохраняются в after_silence/assets/ppae0300. Настройки палитр, одежды, мебели и зданий находятся в after_silence/tools/ppae/profiles.json. Базовый seed равен 304211.

## Что участвует в игре

| Область | Откуда берётся графика |
|---|---|
| Вера, жители и противники | Восьминаправленные риги и SpritesheetCompiler. У Веры исходное лицо и хвост совмещены с новым телом по опорной точке головы. Для движений использованы отдельно сгенерированные кадры. |
| Земля, тропы и площадь | DeterministicWorldField и ChunkWorldRenderer дают банк материалов для исходных TileMapLayer. TerrainAutotiler даёт землю, песок и исходную фактуру мощения. Видимые дороги прорисованы по существующим сегментам. |
| Лес и растительность | Три семейства из NatureGenerator, варианты по seed, анимация крон. Форма проходимых участков и координаты существующих деревьев сохранены. |
| Дома и колодец | Фасады и крыши проходят через StructureGenerator. Фактура переносится с учётом исходного контура, источника света и рисунка древесины. Для окон запекается отдельный слой. |
| Интерьеры | InteriorGenerator запекает пол и спрайты мебели. Текстуры доработаны под комнатные палитры, геометрия пола и точки у мебели остаются исходными. |
| Вода | LiquidTileGenerator даёт восемь фаз по двум глубинам. Шейдер применяет их к существующему полю Watercourse. Берег разрешается в мировых координатах. |
| Свет, ветер, погода и частицы | PixelPerfectLightingEngine, WeatherAndWindSystem и PixelParticleEngine дают профиль суток, маску локального света, кадры дождя и тумана, частицы шага и попадания. Godot воспроизводит эффекты в существующих сценах и учитывает настройку анимаций. |
| HUD и окна | PixelNineSliceLibrary запекает девятисегментные панели. Кнопки сохраняют назначение и клавиатурный фокус. |

Экспортёр записывает координаты кадра, опоры, длительность, события и справочные хитбоксы PPAE. Godot собирает SpriteFrames из JSON и PNG. Хитбоксы PPAE не участвуют в столкновениях игры. У попаданий отдельная сцена с AnimationPlayer.

Сохранены иллюстрация главного меню, портреты диалогов, сюжетные предметы и авторские детали уникальных локаций. Такие ресурсы служат ориентирами для оформления новых материалов и анимаций.

## Проверка PPAE

Ветка master клонирована на ревизии ed98da220d9ac30e35b23da555d60f5a0ec84a51. Установка зависимостей и сборка библиотеки и Playground завершились успешно. Локальный Playground проверен в Firefox. TypeScript-проверка прошла после сборки пакета и локальной установки @types/node без изменения lock-файла PPAE. В npm test прошли 203 из 204 тестов. Оставшийся тест проверяет старые пути к испанскому и португальскому README, размещённым в корне upstream. Исходники PPAE не изменялись.

Лицензия PPAE хранится в after_silence/third_party/PPAE_APACHE_LICENSE.txt.
