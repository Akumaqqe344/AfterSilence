# Оформление и движение · 0.2.0

Активные игровые текстуры перенесены из пользовательского Pechatai, коммит 9fe814e08fdb1f708fa327eff5110943546bc781. Новая графика не генерировалась. Файлы Pechatai не изменены. Перенесены атласы ходьбы, бега, диагоналей, idle и прыжков; пять NPC; четыре дома; три дерева; трава, тропа, вода, растительность, камни и интерьерные предметы. Файлы и SHA-256 перечислены в assets/pechatai/provenance.json. Использование в этом проекте прямо запрошено владельцем Pechatai; это не заявление о публичной лицензии всех исходных ресурсов.

`world/pechatai_actor.gd` переносит модель из character.js/player-sprites.js: скорость 180, бег ×1.65, ускорение 1300, торможение 1600, нормализованный ввод, восемь направлений, короткий прыжок .44 с высотой 28 и длинный .68 с высотой 52. Пробел — прыжок, Shift+Пробел — длинный. Коллизии выполняет CharacterBody2D; воздушная анимация не разрешает проходить сквозь стены. Коллизии Pechatai на JS не исполняются в Godot: сохранены параметры и поведение, используется физический сервер движка.

Размер NPC нормализуется по занятой области первого кадра, портреты вырезаются по ней же: прозрачные поля исходных атласов различаются. Карты авторские; сюжет, головоломки, предметы и сохранения After Silence сохранены. В обычном мире применён приглушённый зелёный оттенок; отголосок холодный сине-лиловый. Земля использует исходные текстуры вместо одноцветной процедурной заливки.

Интерфейс изучен по HazardWare/Hazardous-Quest, коммит a51140dfd1d1b71ed24585ddba8c0bc868aff739: полупрозрачные тёмные панели, толстые контуры, пиксельные края и компактные слоты. В доступном репозитории отсутствует LICENSE и лицензирование ресурсов не объяснено. Его изображения, шрифты и код не скопированы в распространяемый проект. Компоновка воспроизведена собственным кодом, палитра адаптирована к расследованию. HUD показывает настоящие заряды отголоска; кнопки журнала, инвентаря, смены реальности и паузы работают. Полосы здоровья и боевые индикаторы не добавлялись к игре без боевой механики.

Исторические материалы imagegen из версии 0.1 остаются в Git; активные персонажи, дома, деревья и интерьерные спрайты версии 0.2 берутся из Pechatai. Документ ASSET_PROVENANCE.md описывает происхождение версии 0.1, этот файл уточняет текущую поставку.
