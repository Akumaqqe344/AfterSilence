# Совместимость сохранений

У игры прежнее пользовательское имя `AfterSilenceDesktop` и тот же проверяемый конверт v2 с полезной нагрузкой схемы 3. Поля `archive_boards` и `case_orders` необязательны. История, слоты и сюжетные флаги продолжаются по состоянию существующего профиля.

| Сценарий | Что подтверждено |
| --- | --- |
| Реальный файл 0.33.0 | Слот, созданный базовым 0.33.0 EXE в отдельном QA-профиле, прочитан новым загрузчиком. Кампания, финал и флаги переклички сохранились. |
| Выход с незаконченной доской | Отдельные процессы Godot записали и загрузили принятый ход сюжетного испытания. |
| Устройство и диалог | Слот, записанный в комнате при открытом диалоге, вернул Веру на нижний причал. Восстановлены лебёдка, два шага хронологии и решение об архивной подписи. |
| Перед финалом | При загрузке последняя встреча остаётся доступной, законченные дела остаются зачтёнными. |
| Повреждённый первичный файл | Проверяемый резерв прочитан, следующий сейв сохраняет его контрольную сумму. Исходный повреждённый файл помещается в отдельный `.unreadable-*`. |
| Основной и резерв нечитаемы | Интерфейс показывает проблему и возвращает в меню. Автоматического удаления нет. |

Все тесты работали с QA-слотами. В стадии восстановления выбирается первый файл с корректным конвертом и допустимым состоянием. Если при предрелизном тестировании нужно отдельно сохранить старое прохождение, достаточно скопировать папку профиля перед запуском.
