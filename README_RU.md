# After Silence 0.9.0 Pre-Release

Сюжетное 2D-приключение о Вере, которая собирает свидетельства о ночи наводнения и решает, какие сведения могут прозвучать на площади.

## Запуск

Распакуйте портативный ZIP в отдельную папку и запустите `AfterSilence-0.9.0-PreRelease.exe` на Windows x64. Движок Godot встроен в EXE. Эта сборка предназначена для независимого тестирования. Предыдущая 0.33.0 остаётся отдельной сборкой.

«Новое путешествие» включает 13 расследований, 12 сюжетных испытаний и семь дополнительных дел. «Продолжить» открывает имеющееся сохранение, сохраняя прежние обязательные главы. Через «Настройки → Архив» можно открыть отдельный архивный эпизод и кампанию «Разлом».

| Управление | Действие |
| --- | --- |
| WASD или стрелки | Движение |
| E | Осмотр, разговор, вход |
| Shift / Пробел | Бег / прыжок |
| J / T / M / I | Журнал / путешествие / карта / инвентарь |
| Esc | Назад или пауза |
| Tab, стрелки, Enter, мышь | Интерфейс и головоломки |

В настройках доступны русский и английский, крупный текст, уменьшенное движение, мгновенный показ текста и отдельные уровни общей громкости, музыки и эффектов.

Сохранения используют прежний профиль `%APPDATA%\AfterSilenceDesktop`. Перед новым путешествием можно скопировать профиль для отдельного плейтеста. Основная история, архив и «Разлом» сохраняются раздельно. Подробности в [отчёте о совместимости](SAVE_COMPATIBILITY.md).
