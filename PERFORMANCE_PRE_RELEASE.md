# Производительность 0.9.0 Pre-Release

Замер выполнен на доступной Windows с Intel Core i5‑1335U и Intel Iris Xe Graphics. Godot 4.7.2, OpenGL Compatibility, фактическое окно 1920×1080, VSync отключён. Игровой процесс продолжал обновлять среду и NPC. На каждую локацию после прогрева собрано 240 интервалов отрисовки. Это короткий тест исходного проекта из предрелизной ветки.

| Локация | Средний FPS | P95, мс | P99, мс | Память движка, МиБ |
| --- | ---: | ---: | ---: | ---: |
| Площадь | 76,4 | 14,74 | 18,19 | 81,75 |
| Закрытое отделение | 488,9 | 4,42 | 4,66 | 77,98 |
| Зал звукозаписей | 504,1 | 4,35 | 4,77 | 77,98 |
| Просека | 589,9 | 3,52 | 4,22 | 78,28 |
| Нижний причал | 381,5 | 5,69 | 6,33 | 78,45 |

Площадь дала отдельные кадры длиннее 16,7 мс. При одновременно работавшем автоматическом прогоне среднее на площади составило 52,4 FPS, P95 — 27,82 мс. Частота в небольших комнатах отражает замер с отключённым VSync и отличается от частоты обновления дисплея. Стабильные 60 FPS под нагрузкой пока не подтверждены.

Число объектов движка после четырёх возвратов из архива на площадь составило 5 321, 5 320, 5 324 и 5 328. Такой короткий тест показывает лишь состояние после нескольких переходов. Для вывода об утечке нужен длительный повтор. Числа памяти относятся к аллокатору Godot. Windows не вернула надёжных значений CPU и полного рабочего набора для процесса из изолированного окружения.

До 1.0 нужен длительный прогон Windows EXE с включённым VSync. Снимите 1% low, CPU, RSS и VRAM при движении по площади, переключении хроники и прохождении головоломок на целевом ноутбуке.
