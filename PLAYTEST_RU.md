# Инструкция для независимого тестировщика

1. Распакуйте Windows ZIP. Закройте прежнюю игру, если она запущена, и запустите EXE из новой папки.
2. Выберите «Новое путешествие». Для первого прохождения оставьте подсказки в настройках по умолчанию. Если на машине есть личное прохождение, прежде сделайте копию папки `%APPDATA%\AfterSilenceDesktop`.
3. Начните отсчёт, когда Вера впервые становится доступна для управления. Отдельно запишите время до экрана финала и время дополнительных дел. Исключите перерывы.
4. Когда неясно следующее действие, отметьте комнату, заголовок задачи и сколько времени вы искали путь. Обращение к журналу или подсказке — полезная часть наблюдения.
5. После основного прохода перезапустите игру с сохранением во время устройства или головоломки. Проверьте комнату, этап, введённые данные и возможность продолжить.
6. В отдельной сессии откройте «Настройки → Архив», пройдите каталог, часы и реле. Проверьте, видна ли причина отказа и можно ли восстановиться после ошибки.
7. В настройках проверьте уровни музыки и эффектов отдельно, крупный текст и переключение языка.

## Что указать в отчёте

| Поле | Наблюдение |
| --- | --- |
| Версия, Windows, CPU/GPU, размер окна | |
| Время основной линии / побочных дел | |
| Дело или комната, где стало непонятно | |
| Ожидание и фактическое поведение | |
| Действия для повторения | |
| Какие настройки были включены | |
| Потребовался ли перезапуск | |
| Было ли сохранение создано в 0.33.0 | |

Для первого прохода используйте только игру. Сценарные данные, Vault и QA-прогоны содержат решения и спойлеры.
